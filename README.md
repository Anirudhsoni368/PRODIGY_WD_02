# PRODIGY_WD_02

## Prodigy InfoTech Web Development Internship - Task 2

### Stopwatch Web Application

This project is an interactive stopwatch web application developed using HTML, CSS, and JavaScript.

### Features

* Start the stopwatch
* Pause the stopwatch
* Resume the stopwatch
* Reset the stopwatch
* Record multiple lap times
* Display time with millisecond precision
* Responsive user interface
* Interactive buttons and hover effects

### Technologies Used

* HTML5
* CSS3
* JavaScript
